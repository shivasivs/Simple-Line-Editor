# Simple Line Editor - Help

## 1. Insert Line

Adds a new line at the given line number.

Example:

1. Select `Insert Line`
2. Enter line number: `2`
3. Enter text: `Hello World`

The new line is inserted at line 2.

---

## 2. Delete Line

Deletes a line using its line number.

Example:

1. Select `Delete Line`
2. Enter line number: `2`

The second line is deleted.

---

## 3. Display Document

Displays all current lines with their line numbers.

Example:

```text
1 | Hello World
2 | C Programming
3 | Line Editor
