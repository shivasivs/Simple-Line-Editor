## Project Description

Simple Line Editor is a command-line text editor developed in C.

It allows the user to create, view, modify, save and load a small text document using the terminal.

## Build and Run

1. Make sure a C compiler such as GCC is installed.
2. Compile the program from the project folder:

~~~bash
gcc main.c -o editor
~~~

3. Start the editor:

~~~bash
./editor
~~~

## Features

- Insert a line
- Delete a line
- Display the document
- Save the document to a text file
- Load a document from a text file
- Search for a word or phrase
- Help command

## Data Structure

The editor uses an array of strings to store the document lines.
