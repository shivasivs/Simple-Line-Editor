## Project Description

Simple Line Editor is a command-line text editor developed in C.

It allows the user to create, view, modify, save and load a small text document using the terminal.

## Features

- Insert a line
- Delete a line
- Display the document
- Save the document to a text file
- Load a document from a text file
- Search for a word or phrase
- Help command
